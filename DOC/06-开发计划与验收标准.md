# ChatAI 第一版开发计划与验收标准

## 1. 第一版目标

第一版交付一个完整可用的 ChatAI Web 项目：

- 前端：React + TypeScript。
- 后端：Python + FastAPI。
- 数据库：PostgreSQL。
- 模型：通过可配置 API 调用。
- 核心体验：高度贴近 ChatGPT Web 版文字对话体验。
- 企业能力：账号、角色、权限、管理后台、模型管理和日志审计。

## 2. 里程碑拆分

### M1：项目基础架构

目标：跑通前后端基础工程。

前端：

- 创建 React + TypeScript 工程。
- 配置路由、请求封装、主题、基础布局。
- 建立用户端布局和管理端布局。

后端：

- 创建 FastAPI 工程。
- 配置数据库连接、ORM、迁移。
- 建立统一响应、错误处理、日志。
- 建立认证依赖和权限依赖。

数据库：

- 初始化用户、角色、权限、模型、助手预设表。
- 初始化超级管理员账号。

验收：

- 前后端可本地启动。
- 登录接口可用。
- 数据库迁移可重复执行。
- OpenAPI 文档可访问。

### M2：账号与权限

目标：完成企业内部使用的账号与权限基础。

功能：

- 登录。
- 退出。
- Token 刷新。
- 当前用户信息。
- 用户列表。
- 新增用户。
- 禁用/启用用户。
- 重置密码。
- 角色列表。
- 角色权限绑定。
- 前端路由权限控制。

验收：

- 普通用户不能访问后台。
- 管理员可以管理普通用户。
- 管理员不能提升自己为超级管理员。
- 超级管理员可以维护角色权限。
- 关键管理操作写入日志。

### M3：Chat 主流程

目标：完成 ChatGPT 风格核心对话体验。

功能：

- Chat 主页面。
- 新建会话。
- 发送用户消息。
- 调用模型 API。
- SSE 流式输出。
- 停止生成。
- 历史会话列表。
- 会话详情。
- Markdown 渲染。
- 代码块高亮和复制。

验收：

- 用户发送消息后 AI 能流式输出。
- 生成中可停止。
- 刷新页面后会话和消息仍在。
- 普通用户只能看到自己的会话。
- 模型调用失败有友好提示。

### M4：会话增强

目标：补齐 ChatGPT 类体验的会话管理和回答控制。

功能：

- 会话自动命名。
- 会话重命名。
- 会话搜索。
- 删除会话。
- 归档会话。
- 收藏会话。
- 重新生成。
- 编辑问题并重新生成。
- 点赞点踩。
- 临时聊天。

验收：

- 会话列表按时间分组。
- 搜索能命中标题和消息内容。
- 编辑问题后能重新生成回答。
- 重新生成能生成新回答版本。
- 临时聊天不进入历史记录。

### M5：模型管理与系统设置

目标：支持企业后台配置模型和系统策略。

功能：

- 模型列表。
- 新增模型。
- 编辑模型。
- 禁用模型。
- 设置默认模型。
- 配置模型可见角色。
- 测试模型连通性。
- 系统设置。
- 会话策略设置。

验收：

- 普通用户只能看到自己有权限使用的模型。
- 管理员可以启用或禁用模型。
- 模型 API Key 不返回前端。
- 默认模型配置生效。
- 禁用模型后用户不可再选择。

### M6：后台统计、日志与上线准备

目标：完成可运营和可审计能力。

功能：

- 后台首页统计。
- 登录日志。
- 操作日志。
- 模型调用日志。
- 基础错误日志。
- 数据导出。
- 分享链接，可根据工期放入 v1.1。

验收：

- 后台首页展示关键指标。
- 模型调用记录 Token、耗时、状态。
- 登录成功和失败均记录日志。
- 管理操作可追溯。
- 上线前测试通过。

## 7. 验收标准

### 7.1 对话体验

- 页面整体结构接近 ChatGPT Web。
- 输入框交互自然。
- AI 回答实时流式输出。
- 生成过程可停止。
- Markdown、代码块、表格显示正确。
- 多轮上下文可用。
- 刷新页面后历史会话保留。

### 7.2 会话管理

- 会话可创建、查看、重命名、删除。
- 会话可归档、收藏。
- 会话搜索可命中标题和消息内容。
- 用户只能看到自己的会话。
- 临时聊天不保存到历史。

### 7.3 权限管理

- 未登录不能访问业务页面。
- 普通用户不能访问后台。
- 管理员能管理普通用户。
- 管理员不能提升为超级管理员。
- 超级管理员可管理角色权限。
- 管理员默认不能查看用户会话正文。
- 关键操作有日志。

### 7.4 模型管理

- 后台可新增、编辑、禁用模型。
- 用户只能看到有权限的模型。
- 模型不可用时前端提示清晰。
- 模型调用日志记录完整。
- API Key 不泄露到前端。

### 7.5 UI 与兼容

- Chrome、Edge、Safari 最新主流版本可用。
- 桌面端体验完整。
- 移动端可完成基础聊天。
- 深色和浅色主题均可读。
- 长文本、代码块和表格不会破坏布局。

## 9. 风险与处理

|风险|影响|处理|
|---|---|---|
|模型 API 不稳定|回答失败、超时|增加超时、错误提示、模型切换|
|流式接口中断|体验差|前端支持重试，后端保留已生成内容|
|权限遗漏|数据越权|后端统一权限依赖和资源归属校验|
|消息内容过长|上下文超限|按模型上下文裁剪历史消息|
|搜索性能下降|会话搜索慢|建立全文索引，必要时后续接搜索引擎|
|管理后台范围膨胀|延期|第一版只做用户、角色、模型、日志和统计|

## 10. 第一版完成定义

满足以下条件即可定义为第一版完成：

- 普通用户可以稳定完成多轮 AI 对话。
- 页面交互接近 ChatGPT Web 的核心体验。
- 会话历史和消息数据完整保存。
- 管理员可以管理用户、角色和模型。
- 超级管理员可以管理系统级权限。
- 普通用户和管理员权限边界清晰。
- 模型通过 API 调用，支持流式输出。
- 关键操作和模型调用有日志。
- P0 功能全部完成，P1 核心功能完成。
