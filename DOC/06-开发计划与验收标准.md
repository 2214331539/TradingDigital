# TradeDigital 开发计划与验收标准

## 1. 当前重构步骤

1. 创建重构分支：`feat/tradedigital-platform`。
2. 备份旧库：`backend/chatai.backup.db`。

4. 新建 Platform / llm / KnowledgeBase 模块边界。

10. 更新一键启动脚本 `start.sh`。

## 2. 本地启动顺序

推荐直接执行：

```bash
./start.sh
```

手动启动：

```bash
cd infra
docker compose up -d

cd ../backend
cp .env.example .env
uv run alembic upgrade head
uv run python -m tradedigital.scripts.seed
uv run uvicorn tradedigital.main:app --reload --host 127.0.0.1 --port 8000

cd ../frontend
npm install
npm run dev
```

访问地址：

```text
前端：http://127.0.0.1:5173
后端：http://127.0.0.1:8000
Keycloak：http://127.0.0.1:8080
```

## 4. 第一版验收标准

1. 用户访问 `/login` 可以进入 SSO 登录流程。
2. 登录后进入 `/app` 模块入口页。
3. employee 在模块入口页只能看到 `llm`。
4. enterprise_admin 在模块入口页可以看到 `llm`、知识库和企业管理。
5. employee 访问企业管理 API 返回 403。
6. enterprise_admin 可以查看用户列表。
7. enterprise_admin 可以修改员工角色。
8. 员工只能看到自己的会话。
9. 模型列表根据角色过滤。
10. 所有 llm 对话请求必须登录后才能调用。
11. 所有权限不足请求返回 403。
12. 登录、改角色、调用模型都会写入审计日志。
