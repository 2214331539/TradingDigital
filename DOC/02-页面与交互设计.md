# TradeDigital 页面与交互设计

## 1. 路由

```text
/login
/app
/app/llm
/app/knowledge
/admin
/admin/users
/admin/roles
/admin/audit-logs
/403
```

## 2. 登录页

登录页只显示：

```text
电商数字化 TradeDigital
使用企业 SSO 登录
```

前端不提供账号密码输入框。账号密码由 Keycloak 登录页负责。

## 3. 模块入口页

登录后进入 `/app` 模块入口页，而不是直接进入某一个业务模块。

模块入口页以卡片形式展示当前用户可访问的功能模块：

|导航|显示权限|
|---|---|
|llm|`llm.chat.use`|
|知识库|`kb.knowledge_base.read`|
|企业管理|`platform.admin.access`|

员工默认只看到 `llm` 卡片。企业管理员默认看到 `llm`、知识库和企业管理卡片。

点击模块卡片后进入对应独立工作区：

```text
llm → /app/llm
知识库 → /app/knowledge
企业管理 → /admin
```

## 4. llm 页面

`llm` 保留 ChatGPT Web 风格的核心布局：

```text
左侧会话栏
├── New chat
├── Search chats
├── Pinned
├── Projects
└── Chats

中间对话区
├── 顶部模块名、模型选择、助手预设
├── 消息列表
└── 底部输入器
```

交互要求：

- Enter 发送，Shift + Enter 换行。
- 生成中可以停止。
- SSE 增量渲染。
- 会话可以置顶、归档、删除。
- 会话默认只显示当前用户自己的非归档会话。
- 模型列表由后端按角色过滤后返回。

## 5. KnowledgeBase 页面

第一版提供知识库列表入口。llm 不直接查询 `kb_` 表，需要通过 KnowledgeGateway 调用知识库能力。

## 6. 管理后台

管理后台页面：

- `/admin`：企业管理总览。
- `/admin/users`：用户列表、启用/禁用、分配角色。
- `/admin/roles`：角色权限查看与调整。
- `/admin/audit-logs`：审计日志。

管理员第一版不查看员工会话正文。

## 7. 前端鉴权

前端启动后必须请求：

```text
GET /api/v1/auth/me
```

前端保存：

```text
user
enterprise
roles
permissions
isAuthenticated
loading
```

禁止保存：

```text
OIDC access_token
OIDC id_token
session token
client_secret
```
