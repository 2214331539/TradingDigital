# ChatAI 页面与交互设计

## 1. 设计目标

第一版 UI 目标是高度贴近 ChatGPT Web 版的核心交互：

- 左侧深色/浅色会话侧边栏。
- 中间极简对话阅读区。
- 底部悬浮式多行输入框。
- 顶部模型选择器。
- 消息流式生成。
- 会话历史按时间分组。
- 设置弹窗和头像菜单。
- 管理后台独立布局。

边界说明：允许参考 ChatGPT Web 的信息架构、交互模式和体验节奏，但不复制其商标、Logo、专有图形资产和品牌文案。

## 2. 路由结构

|路由|页面|权限|
|---|---|---|
|`/login`|登录页|未登录|
|`/forgot-password`|忘记密码|未登录|
|`/`|默认跳转 Chat 首页|登录用户|
|`/c/:conversationId`|Chat 会话页|会话所有者或分享权限|
|`/temporary`|临时聊天|登录用户|
|`/archived`|归档会话|登录用户|
|`/favorites`|收藏会话|登录用户|
|`/projects`|项目列表|登录用户，v1.1 可延后|
|`/settings`|个人设置|登录用户|
|`/share/:token`|分享只读页|按分享策略|
|`/admin`|管理后台首页|管理员、超级管理员|
|`/admin/users`|用户管理|`user:read`|
|`/admin/roles`|角色管理|`role:read`|
|`/admin/permissions`|权限管理|`permission:read`|
|`/admin/models`|模型管理|`model:read`|
|`/admin/settings`|系统设置|`system:read`|
|`/admin/logs`|日志管理|`log:read`|
|`/admin/analytics`|使用统计|`analytics:read`|

## 3. 用户端页面

### 3.1 登录页

#### 页面元素

- 产品 Logo 或文字标识 `ChatAI`。
- 邮箱输入框。
- 密码输入框。
- 登录按钮。
- 忘记密码入口。
- 注册入口，可根据系统设置隐藏。

#### 交互

- 邮箱格式校验。
- 密码为空校验。
- 登录中按钮 loading。
- 登录失败展示错误原因。
- 登录成功后跳转最近会话或 Chat 首页。
- 已登录访问 `/login` 自动跳转 `/`。

### 3.2 Chat 主页面

Chat 主页面是第一版最重要页面。

#### 桌面端布局

```text
+----------------------+----------------------------------------+
| Sidebar              | Header                                 |
|                      +----------------------------------------+
| New Chat             |                                        |
| Search               | Message List                           |
| History Groups       |                                        |
|                      |                                        |
| Projects/Favorites   |                                        |
|                      +----------------------------------------+
| User Menu            | Composer                               |
+----------------------+----------------------------------------+
```

#### 左侧侧边栏

宽度建议 260px 到 300px。

功能：

- 新建聊天。
- 搜索会话。
- 会话历史列表。
- 收藏入口。
- 归档入口。
- 项目入口，可 v1.1 延后。
- 用户头像菜单。
- 收起侧边栏按钮。

会话分组：

- 今天。
- 昨天。
- 最近 7 天。
- 最近 30 天。
- 更早。

会话项展示：

- 标题。
- 当前选中态。
- 收藏标记。
- 更多操作。

会话更多菜单：

- 重命名。
- 收藏/取消收藏。
- 归档/取消归档。
- 分享。
- 删除。

#### 顶部栏

顶部栏元素：

- 侧边栏展开按钮，侧边栏收起时显示。
- 当前会话标题。
- 模型选择器。
- 临时聊天状态。
- 分享按钮。
- 管理后台入口，仅管理员可见。

#### 消息区

消息区展示：

- 空白欢迎态。
- 用户消息。
- AI 消息。
- 生成中状态。
- 错误状态。
- 上下文已重置提示。

空白欢迎态：

- 居中显示产品名或欢迎语。
- 显示 4 个示例 Prompt。
- 底部输入框始终可用。

#### 用户消息

用户消息支持：

- 展示原文。
- 复制。
- 编辑。
- 删除。
- 重新提交。

编辑用户消息时：

- 该消息进入编辑态。
- 用户保存后，系统删除或隐藏该消息之后的消息。
- 后端基于编辑后的上下文重新生成 AI 回答。

#### AI 消息

AI 消息支持：

- Markdown 渲染。
- 代码块高亮。
- 表格横向滚动。
- 数学公式。
- 复制全文。
- 重新生成。
- 点赞。
- 点踩。
- 删除。

AI 消息状态：

|状态|展示|
|---|---|
|`streaming`|正在逐字输出，展示停止按钮|
|`completed`|展示操作按钮|
|`stopped`|展示“已停止生成”和继续生成按钮|
|`failed`|展示错误提示和重试按钮|

#### 底部输入框

输入框要求：

- 多行输入。
- 自动增高。
- 最大高度后内部滚动。
- Enter 发送。
- Shift + Enter 换行。
- 输入为空时发送禁用。
- 生成中发送按钮变为停止按钮。
- 支持粘贴多行文本。
- 支持本地草稿保存。

输入框附加入口：

- 模型选择。
- 助手选择。
- 临时聊天提示。
- 未来可预留附件按钮，但第一版不实现文件上传。

### 3.3 会话搜索弹窗

快捷键：`Ctrl/Cmd + K`。

页面元素：

- 搜索输入框。
- 最近会话。
- 命中结果列表。
- 空结果提示。

搜索范围：

- 会话标题。
- 用户消息内容。
- AI 消息内容。

结果展示：

- 会话标题。
- 命中片段。
- 更新时间。
- 所属状态，例如已归档、已收藏。

### 3.4 临时聊天页

临时聊天用于不保存历史记录的对话。

特征：

- 页面顶部展示临时聊天提示。
- 不进入历史列表。
- 刷新后不可恢复。
- 不参与会话自动命名。
- 不参与数据导出。
- 用户可选择保存为普通会话。

### 3.5 个人设置页

建议第一版使用 Dialog 或独立页面均可。桌面端可以采用弹窗，移动端使用整页。

设置分组：

- 账号资料：昵称、头像、邮箱。
- 安全设置：修改密码、退出所有设备。
- 外观：浅色、深色、跟随系统。
- 默认模型：用户默认模型。
- 默认助手：用户默认助手。
- 数据控制：导出会话、清空会话、管理分享。
- 快捷键：展示快捷键说明。

### 3.6 分享只读页

分享页用于展示会话快照。

要求：

- 只读展示。
- 不显示输入框。
- 可根据分享设置显示或隐藏分享者信息。
- 分享失效时展示失效页。
- 企业内部部署默认要求登录后访问。

### 4.1 后台首页

- 今日消息数。
- 今日模型调用次数。

功能：

- 用户列表。

- 编辑用户。

功能：

- 角色列表。
- 新增角色。
- 编辑角色。

- 配置权限。
- 查看角色下用户。

内置角色：

- 超级管理员不可删除。

### 4.4 权限管理

功能：

- 权限列表。
- 按模块筛选。
- 查看权限说明。
- 维护角色权限绑定。

第一版权限项可内置，不要求后台新增任意权限码。

### 4.5 模型管理

功能：

- 模型列表。
- 新增模型。
- 编辑模型。
- 禁用模型。

模型表单：

- 显示名称。
- 模型标识。

## 5. 响应式规则

### 5.1 桌面端

- 侧边栏默认展开。
- 输入框最大宽度建议 760px 到 900px。
- 消息区居中展示。
- 管理后台采用侧边栏布局。

### 5.2 平板端

- 侧边栏可折叠。
- 会话列表覆盖式抽屉。
- 输入框宽度占满内容区。

### 5.3 移动端

- 侧边栏默认隐藏。
- 点击菜单按钮打开侧边栏抽屉。
- 消息操作按钮可折叠到更多菜单。
- 管理后台移动端只保证基础可用。

## 6. 通用状态设计

|状态|要求|
|---|---|
|Loading|骨架屏或轻量 loading|
|Empty|提供明确空状态和主操作|
|Error|说明错误原因并提供重试|
|No Permission|展示无权限提示，不泄露资源内容|
|Not Found|资源不存在或已删除|
|Offline|提示网络异常，保留输入内容|

## 7. 关键体验验收

- 新建聊天后第一屏应像 ChatGPT 一样聚焦输入。
- AI 回答必须流式展示，而不是等待完整响应后一次性显示。
- 停止生成应在 1 秒内生效或给出明确状态反馈。
- 历史会话刷新页面后仍然存在。
- 输入框在长文本、多行、移动端下不遮挡消息。
- 深色模式下 Markdown、代码块、表格可读。
- 管理员入口只对有权限用户可见。
