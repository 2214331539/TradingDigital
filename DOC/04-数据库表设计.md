# TradeDigital 数据库表设计

## 1. 数据库

```text
PostgreSQL 数据库名：tradedigital
```

开发环境和生产环境统一使用 PostgreSQL。旧 `backend/chatai.db` 只保留为备份，不再作为主数据库写入。

## 2. 表前缀

|前缀|模块|
|---|---|
|core_|平台核心|
|iam_|身份认证与权限|
|audit_|审计日志|
|llm_|llm|
|kb_|KnowledgeBase|

禁止创建无前缀表，例如 `users`、`roles`、`messages`、`documents`、`logs`。

## 3. Platform 表

```text
core_enterprises
core_app_settings
iam_users
iam_roles
iam_permissions
iam_user_roles
iam_role_permissions
iam_sso_connections
iam_auth_states
iam_sessions
audit_operation_logs
```

关键字段：

- `core_enterprises`: id, name, code, status, created_at, updated_at
- `iam_users`: id, enterprise_id, sso_provider, sso_subject, email, name, avatar_url, status, last_login_at
- `iam_roles`: id, enterprise_id, code, name, description, is_system
- `iam_permissions`: id, code, name, module, resource, action, description
- `iam_sessions`: id, enterprise_id, user_id, session_token_hash, expires_at, revoked_at
- `audit_operation_logs`: id, enterprise_id, user_id, module, action, resource_type, resource_id, detail_json

## 4. llm 表

```text
llm_models
llm_model_role_grants
llm_assistant_presets
llm_conversations
llm_messages
llm_model_call_logs
```

关键字段：

- `llm_models`: id, provider_code, model_key, display_name, type, base_url, api_key_ref, support_streaming, enabled
- `llm_model_role_grants`: model_id, role_id, created_at
- `llm_assistant_presets`: id, enterprise_id, name, system_prompt, visibility, created_by, enabled
- `llm_conversations`: id, enterprise_id, user_id, title, assistant_preset_id, model_id, archived, pinned, temporary
- `llm_messages`: id, enterprise_id, conversation_id, user_id, role, content, metadata_json
- `llm_model_call_logs`: id, enterprise_id, user_id, conversation_id, model_id, provider_code, status, latency_ms

## 5. KnowledgeBase 表

```text
kb_knowledge_bases
kb_data_sources
kb_documents
kb_chunks
kb_tools
kb_role_grants
kb_tool_role_grants
kb_query_logs
```

关键字段：

- `kb_knowledge_bases`: id, enterprise_id, name, description, type, status, created_by
- `kb_role_grants`: knowledge_base_id, role_id
- `kb_tools`: id, enterprise_id, knowledge_base_id, name, code, schema_json, endpoint_url, enabled
- `kb_tool_role_grants`: tool_id, role_id
- `kb_query_logs`: id, enterprise_id, user_id, knowledge_base_id, query, result_json

## 6. 企业隔离规则

所有业务表必须包含：

```text
enterprise_id
```

所有个人资源表额外包含：

```text
user_id
```

llm 普通员工会话查询固定条件：

```python
AiConversation.enterprise_id == ctx.enterprise_id
AiConversation.user_id == ctx.user_id
```

禁止业务查询遗漏 `enterprise_id`。
