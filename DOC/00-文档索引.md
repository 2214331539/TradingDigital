# ChatAI 第一版开发文档索引

## 1. 项目目标

ChatAI 第一版的目标是开发一个高度贴近 ChatGPT Web 版核心体验的 AI 对话系统，并补充企业内部可用的账号、角色、权限和管理后台能力。

第一版不做知识库、RAG、插件、联网搜索、图片生成、语音和多 Agent。第一版只把 ChatGPT 风格的文字对话产品做完整、稳定、可用。

## 3. 第一版交付范围

### 3.1 用户端

- 登录、退出、登录态保持。
- ChatGPT 风格 Chat 主页面。
- 新建聊天、多轮对话、流式回答、停止生成。
- 编辑上一条问题并重新生成。
- 重新生成回答、复制回答、点赞点踩。
- Markdown、代码块、表格、数学公式渲染。
- 会话自动命名、重命名、搜索、删除、归档、收藏。
- 临时聊天。
- 模型选择、默认模型。
- 助手预设。
- 个人设置、主题切换、数据导出。

### 3.2 管理端

- 管理后台首页。
- 用户管理。
- 角色管理。
- 权限管理。
- 模型管理。
- 系统设置。
- 会话策略管理。
- 使用统计。
- 登录日志、操作日志、模型调用日志。

### 3.3 权限体系

第一版内置三类核心角色：

|角色|定位|
|---|---|
|超级管理员|系统最高权限，负责平台、模型、角色、系统配置和审计能力|
|管理员|企业内部运营管理者，负责用户、基础角色、模型可见范围和使用统计|
|普通用户|主要使用者，只能管理自己的会话、设置和数据|

可预留游客、部门管理员、高级用户，但第一版不作为必须交付。

## 5. 第一版关键原则

- 体验优先：主界面、输入框、流式输出和历史会话体验必须接近 ChatGPT Web。
- 权限内建：账号、角色、权限、模型可见范围和管理后台必须从第一版就进入架构。
- 数据隔离：普通用户只能访问自己的会话；管理员默认不能查看用户会话正文。
- 模型可替换：模型调用通过统一 Provider 接口封装，支持配置 Base URL、API Key、模型标识。
- 企业可扩展：保留组织、租户、审计、模型用量、外部知识服务接口，但第一版不实现复杂企业知识库。

## 6. 明确不做

- 不复制 ChatGPT 商标、Logo、品牌文案和专有视觉资产。
- 不实现知识库、文档上传、向量检索、RAG。
- 不实现联网搜索、插件市场、工作流、多 Agent。
- 不实现图片、语音、视频等多模态能力。
- 不实现复杂多租户计费系统。
