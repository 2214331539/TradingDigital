# TradeDigital 开发文档索引

## 1. 项目定位

项目中文名：**电商数字化**  
项目英文名：**TradeDigital**

TradeDigital 是企业数字化平台，`llm` 是其中的模型对话应用模块。当前重构目标是把原类 ChatGPT 的对话系统纳入统一平台底座，由 TradeDigital 提供企业、SSO、用户、角色、权限和审计能力。

统一命名：

| 项 | 名称 |
|---|---|
| 项目名 | TradeDigital |
| 前端展示名 | 电商数字化 |
| 模型对话模块名 | llm |
| 后端 Python 包名 | tradedigital |
| 数据库名 | tradedigital |
| Session Cookie 名 | td_session |

## 3. 第一版交付范围

- 单仓库 Monorepo。
- React + TypeScript 单前端。
- FastAPI 单后端，后端包名 `tradedigital`。
- PostgreSQL 单业务数据库。
- 模块化单体，不拆微服务。
- Keycloak OIDC SSO 登录。
- 服务端 Session，前端仅持有 HttpOnly Cookie。
- 平台层：企业、IAM、SSO、RBAC、审计。
- 应用层：llm、KnowledgeBase。
- `llm` 保留 ChatGPT 风格对话体验，模型通过 OpenAI Compatible API 调用。

## 4. 核心原则

- SSO 负责解决“你是谁”。
- RBAC 负责解决“你能做什么”。
- `enterprise_id` 负责解决“你属于哪家公司”。
- resource grants 负责解决“你能访问哪些模型、知识库和工具”。
- audit logs 负责解决“你做过什么”。
- `llm` 只负责模型对话体验。
- KnowledgeBase 只负责知识库与工具接入。
