# TradeDigital 技术架构与技术栈选型

## 1. 唯一架构方案

TradeDigital 使用：

```text
单仓库 Monorepo
+ 单前端 React/Vite
+ 单后端 FastAPI
+ 单业务数据库 PostgreSQL
+ 模块化单体 Modular Monolith
+ 外部 OIDC SSO Provider
```

本项目不拆微服务，不为 llm 单独建数据库。

## 2. 系统分层

```text
TradeDigital
├── Platform
│   ├── Enterprise 企业管理
│   ├── IAM 身份认证
│   ├── SSO 单点登录
│   ├── RBAC 角色权限
│   └── Audit 审计日志
│
├── Applications
│   ├── llm 模型对话模块
│   ├── KnowledgeBase 知识库管理
│   └── ECommerceData 电商数据模块
│
└── Infrastructure
    ├── PostgreSQL
    ├── OIDC Provider
    ├── LLM Provider
    └── Vector Store
```

## 3. 后端技术栈

|类别|选型|
|---|---|
|语言|Python >= 3.10|
|Web 框架|FastAPI|
|ORM|SQLAlchemy 2.x Async|
|数据库|PostgreSQL|
|迁移|Alembic|
|SSO|OIDC Authorization Code Flow|
|OIDC Provider|Keycloak|
|Session|服务端 Session + HttpOnly Cookie|
|模型调用|OpenAI Compatible API|
|测试|pytest + FastAPI TestClient|

后端入口：

```text
backend/src/tradedigital/main.py
backend/src/tradedigital/api.py
```

## 7. 本地基础设施

`infra/docker-compose.yml` 固定包含：

- PostgreSQL：`127.0.0.1:55433/tradedigital`
- Keycloak：`127.0.0.1:8080/realms/tradedigital`

`start.sh` 默认使用宿主机 `55433` 映射 PostgreSQL 容器内部 `5432`，避免与本机已有 PostgreSQL 冲突。可通过 `POSTGRES_HOST_PORT=55434 ./start.sh` 覆盖。

启动：

```bash
cd infra
docker compose up -d
```
