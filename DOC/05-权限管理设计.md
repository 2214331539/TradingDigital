# TradeDigital 权限管理设计

## 1. AuthContext

业务模块只能通过依赖注入获取当前身份：

```python
@dataclass(frozen=True)
class AuthContext:
    user_id: str
    enterprise_id: str
    email: str
    name: str | None
    roles: list[str]
    permissions: list[str]
```

禁止业务模块：

- 自己解析 Cookie。
- 自己解析 OIDC Token。
- 直接查询 Session 表。
- 直接读取 `iam_users` 获取用户信息。

## 2. IAM 依赖

```python
get_current_context()
require_permission(permission_code: str)
```

使用方式：

```python
@router.get("/conversations")
async def list_conversations(
    ctx: AuthContext = Depends(require_permission("llm.conversation.read_own")),
):
    ...
```

权限判断必须在后端完成。前端隐藏按钮只用于体验优化。

## 3. 权限码

权限码格式：

```text
模块.资源.动作
```

第一版权限码：

```text
platform.admin.access

iam.user.read
iam.user.manage
iam.role.read
iam.role.manage
iam.permission.read

llm.chat.use
llm.conversation.read_own
llm.conversation.manage_own
llm.model.read
llm.model.manage
llm.preset.read
llm.preset.manage

kb.knowledge_base.read
kb.knowledge_base.manage
kb.query.use
kb.tool.execute

audit.log.read
```

禁止使用中文权限码和模糊权限码，例如 `admin`、`super`、`can_use`、`all`。

## 4. 角色

第一版只允许两个业务角色。

### enterprise_admin

拥有全部权限：

```text
platform.admin.access
iam.user.read
iam.user.manage
iam.role.read
iam.role.manage
iam.permission.read
llm.chat.use
llm.conversation.read_own
llm.conversation.manage_own
llm.model.read
llm.model.manage
llm.preset.read
llm.preset.manage
kb.knowledge_base.read
kb.knowledge_base.manage
kb.query.use
kb.tool.execute
audit.log.read
```

### employee

固定拥有：

```text
llm.chat.use
llm.conversation.read_own
llm.conversation.manage_own
llm.model.read
llm.preset.read
kb.query.use
```

员工不能进入企业管理后台，不能管理用户、角色、模型和知识库。

## 5. 模型权限

模型权限由表控制：

```text
llm_model_role_grants
```

返回模型列表时：

```text
当前用户
→ 当前用户角色
→ 角色可用模型
→ 返回模型列表
```

`POST /api/v1/llm/chat/stream` 必须再次检查当前用户是否可以使用该 `model_id`。

## 6. 会话权限

员工只能访问自己的会话：

```text
enterprise_id = ctx.enterprise_id
user_id = ctx.user_id
```

管理员第一版不提供查看员工会话正文能力。

## 7. 审计日志

以下操作必须写入 `audit_operation_logs`：

- 登录成功。
- 登录失败。
- 退出登录。
- 禁用用户。
- 修改用户角色。
- 修改角色权限。
- 创建知识库。
- 修改知识库权限。
- 调用 AI 模型。
- 调用知识库查询。
- 调用企业工具接口。
- 权限不足访问。

审计日志不能被普通员工查看。
